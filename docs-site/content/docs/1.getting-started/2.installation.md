## Requirements

- Node.js **22** or later (`engines.node` is `>=22`).
- An ES module project. The package is `"type": "module"` and every entry point is exported with `types` and `default` conditions only: there is no CommonJS build.
- A TypeScript `moduleResolution` that honours `exports`: `NodeNext`, `Node16` or `Bundler`.
- A CIRCLE auth-service instance and an application registered in it. See [Register the application](/docs/getting-started/register-the-application).

## Install

```sh
pnpm add @circle-rd/auth-ai
```

```sh
npm install @circle-rd/auth-ai
```

::callout{icon="i-lucide-info" color="info"}
Version `0.1.0` is not published yet, so these commands only work once the first release is out. See [Release channels](/docs/project/release-channels) for how versions reach npm.
::

The SDK depends on `jose`, `openid-client` and `zod`, which npm installs for you.

## Optional peer dependencies

Install only what the entry points you use need. Each one is an optional peer dependency, imported only from its own entry point.

| Entry point | Peer dependency | Range |
| --- | --- | --- |
| `@circle-rd/auth-ai/fastify` | `fastify` | `>=5.12.6` |
| `@circle-rd/auth-ai/react` | `react` | `>=18` |
| `@circle-rd/auth-ai/vue` | `vue` | `>=3.4` |

::callout{icon="i-lucide-triangle-alert" color="warning"}
Keep `fastify` at `5.12.6` or later: several 2026 advisories are fixed there.
::

## Import paths

```ts
// Core: OIDC client, grants, AI clients, claims helpers, errors
import { createAuthClient, GrantManager, createAiClient } from "@circle-rd/auth-ai";

// Backend-for-frontend handlers and session store
import { createAuthHandlers, MemorySessionStore } from "@circle-rd/auth-ai/web";

// Fastify adapter
import { authPlugin, requireAuth, loadSession } from "@circle-rd/auth-ai/fastify";

// Bearer verification, back-channel logout, machine API
import { createBearerVerifier, createMachineApi } from "@circle-rd/auth-ai/server";

// Browser client and stores (no server code)
import { createBrowserAuth } from "@circle-rd/auth-ai/client";

// UI bindings
import { AuthProvider, useAuth } from "@circle-rd/auth-ai/react";
import { createAuthPlugin } from "@circle-rd/auth-ai/vue";
```

Importing from a path that is not in this list fails: the package's `exports` map exposes exactly these seven entry points. The full exports of each are in the [Reference](/docs/reference/core-api).
