The package is published to npm as `@circle-rd/auth-ai` under the **MIT** license, with public access and npm provenance. Version `0.1.0` is **not published yet**.

## Channels

| Channel | Trigger | npm dist-tag | Install |
| --- | --- | --- | --- |
| `nightly` | A manual run of the **Nightly** workflow, with a `branch` input (default `develop`). | `nightly` | `npm install @circle-rd/auth-ai@nightly` |
| `latest` | Push of a `vX.Y.Z` tag from `main`. | `latest` | `npm install @circle-rd/auth-ai` |

### Nightly

A nightly is published as `X.Y.Z-nightly.<date>.g<sha>` (for example `0.1.0-nightly.20261101.g1a2b3c4`), where `X.Y.Z` is the version in `package.json`, `<date>` is the UTC date and `<sha>` the short commit. The version exists only in the workflow's workspace: no commit is made, so no version-bump lands on the branch. The previous nightly is deprecated as "Superseded nightly build" (npm cannot delete a published version, but no dist-tag points at a deprecated one). No GitHub release is created for a nightly.

Use a nightly to try an unreleased change. Nothing about its API is guaranteed.

### Latest

A release is the push of a tag named exactly `vX.Y.Z`. The workflow:

1. runs the same quality gates as continuous integration (type-check, lint, format check, unit tests with a coverage threshold, build, and an audit of production dependencies);
2. requires that the tagged commit is on `main` and that the tag matches the version in `package.json`;
3. builds and publishes with the `latest` dist-tag and provenance;
4. creates the GitHub release with generated notes.

Both publishing workflows need the `NPM_TOKEN` repository secret. See the [Roadmap](/docs/project/roadmap) for the move to npm Trusted Publishing.

## Versioning

The project follows Semantic Versioning. While the major version is `0`, a breaking change bumps the **minor** version. Breaking changes are listed in the [changelog](https://github.com/circle-rd/auth-ai/blob/main/CHANGELOG.md).

## Peer dependencies

`fastify` (`>=5.12.6`), `react` (`>=18`) and `vue` (`>=3.4`) are optional peer dependencies. Node.js `>=22` is required.
